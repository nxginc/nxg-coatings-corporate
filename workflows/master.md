# Master Workflows

## New lead
New source -> ingest -> normalize -> identity/dedupe -> vet -> CRM lead -> opportunity -> notify sales -> follow-up.

## Quote
Quote wizard -> lead -> opportunity -> discovery/site visit -> scope -> estimate -> proposal draft -> human approval -> send -> follow-up -> won/lost -> project.

## Field report
Voice memo/photos/measurements -> transcription -> scope extraction -> media linking -> estimate inputs -> CRM -> proposal.

## Completed project
Project complete -> collect media -> rights check -> classify -> before/after -> render -> case study -> social drafts -> approval -> schedule -> analytics.

## Partner
Application -> validate -> verification -> onboarding -> directory/private portal -> opportunities -> projects -> referrals.

## Career
Approved job -> canonical careers page -> authorized distribution -> candidate ID -> application -> review -> screen/interview -> decision -> offer -> onboarding.

## Finance
Proposal -> approval -> project -> PO/materials -> invoice -> payment -> accounting -> reporting.

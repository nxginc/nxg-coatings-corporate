# NXG Design Contract

## Visual direction
Clean, premium, exclusive, responsive, high-contrast and editorial.

## Required patterns
- parallax hero
- large typography
- split content sections
- split-logo brand presentation
- responsive service cards
- project/service sliders
- strong CTA system
- mobile-first navigation
- CDN-backed imagery
- JSON/API-driven content
- reusable components

## Logo
Use a placeholder only until the approved canonical logo is supplied.

## Shared system
Tokens and components are shared across NXG properties. Content, domain, brand identity and site configuration remain separate.

## Template hierarchy
Brand tokens → Figma components → master template → typed props → asset slots → channel renderer → QA → approval.

# Adapter Layer

Provider-neutral interfaces: CRM, email, SMS, calendar, forms, storage, CDN/media, video, social, ads, analytics, accounting, payments and AI.

Example API: xq.crm.createLead(), xq.media.render(), xq.social.schedule(), xq.email.send(), xq.calendar.book(), xq.accounting.createInvoice().

Directory adapters must document capabilities, terms/compliance, consent/suppression, permitted ingest/export/messaging/webhook behavior and audit output.

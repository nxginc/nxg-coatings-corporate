# Ad Matrix

Dimensions: market, service, geography, intent, audience, funnel stage, creative, offer, channel, landing page and CTA.

No campaign without market + service + audience + destination.

Attribution: AD -> CLICK -> LANDING PAGE -> FORM -> LEAD ID -> OPPORTUNITY -> ESTIMATE -> PROPOSAL -> PROJECT -> INVOICE -> REVENUE.

Budget changes, new campaigns, audience changes, creative publishing, landing-page changes and campaign pauses require approval.
